Those fixes change generated WASM. These historical results do not measure the corrected source, and no new corrected-source speed claim is made. Compilation overlapped part of Chrome on battery; Safari restarted on AC and later Firefox snapshots also showed AC. Safari and Firefox used visible pages, unlike fresh headless Chrome processes. These are separate aggregate observations, not isolated x5 gains or an engine comparison. [M1 results, realtime gaps and conditions](m1-before-after/README.md). ## Second review integration

The second review fixes are integrated through every affected PR without rewriting published history. Modeled execution forwards code-page watches, conditional LEND exits spill held ACCX and production region compilation checks unique chunk heads. New bridge guard tests reject budget, timer, memory-class and pricing mutations. The benchmark harness now uses the production build policy for both arms.

The corrected integration passes 459 native tests with ROMs, 38 native virtual-quantum tests and 86,116 WASM differential cases, with all 88,775 compiled modules released. Both Clippy gates, release and profiling builds, eight production firmware smoke workloads, the timing ABI and production section checks pass. Benchmark unit tests pass 16 Node and 15 Python cases; receipt-verifier tests pass 83 cases. [Commands, source revisions, artifact identity and limitations](second-review-validation.json).
