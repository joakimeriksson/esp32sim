# Conditional helper-copy screen, September 19

The helper-copy candidate remains parked and unadopted. One Pocket Tank pair measured **78.133435 → 77.607040 seconds**, or **0.67% lower wall time**. This small single-pair result does not establish a repeatable gain. No further timing was run as the user requested winding down. [Timing receipt](helper-screen.json).

The candidate constructs the 36-byte temporary helper table only when a cache view is present; otherwise it borrows the existing helper table. This removes work added by cache decoration in EX052. It differs from the old EX030/EX031 experiments, which reused caller-side construction and combined eligibility cleanup. Caller-side sharing already exists in the baseline. [Exact eight-added/two-removed-line patch](helper-source.patch).
