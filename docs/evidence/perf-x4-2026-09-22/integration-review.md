# Integration boundaries checked

The selected source was inspected at `1126546707fb4966e826348e972318b0ba2f6f81` before extraction into six PRs. The final Rust implementation is checked against that source after extraction; targeted validation is recorded in validation.json.

- ACCX: signed-byte products fit the i32 reduction, which widens once and adds the held local when live. The static bound forces a flush before a possible 40-bit overflow. The unheld path sign-extends the low 40 bits, saturates and masks unused high bits. `accx_spill` writes the low word and masked upper byte through two word stores, preserving the same representation. Readers, chunk boundaries and exits retain flush/spill paths. Directed PIE tests cover unaligned and failed shared probes, split runs and accumulator state.
- TLB: writable and code are adjacent u16 fields. WASM loads both with `i32.load16_u`; AArch64 uses `ldrh` with offsets derived from the Rust layout. A compile-time assertion pins the 32-bit-host entry size to 32 bytes. `watch_code_page` marks blocks containing the watched page and its neighboring pages and invalidates published entries, so the previous-page version update may remain behind the code flag. The extracted PR adds an independent assembler comparison for the immediate-offset halfword load.
- Dispatch: cache decoration copies Helpers only when a cache view exists. The no-fast-memory case separately supplies the all-empty TLB table; empty spans reject accesses before dereferencing the null version pointer. These are independent local choices, not alternative branches that bypass one another.
- In-chain interpretation: bridge classes 1/2 are admitted; memory class 3 is not. The pricing, observer, boundary and page-version guards remain. The whitelist must be re-reviewed if instruction classifications change.
