# Correct integer-register operand checks

Instruction fields used as immediates, selectors or floating-point registers were being treated as integer-register operands, causing false register-window overflow exceptions. The standalone correction describes each instruction's actual integer-register effects and uses them for overflow checks. It keeps the existing WASM register-loading mask and leaves the broader execution, interrupt and scheduler changes for further work.

Regression coverage contains 31 independently assembled false-overflow cases and five genuine-overflow controls, exercised through instruction stepping and cached blocks. Corrected semantic goldens are hello-s3 4,295,116 instructions, panel-sid 396,786,672 and reboot 10,307,131. Four reboot-console timestamps move 1 ms earlier; the Atech counts and audio expectations remain unchanged.

Standalone validation totals 176 passing native cases: 175 in the original workspace run plus the corrected reboot-golden rerun. The original run had that one expected golden failure and filtered seven external-input tests; this is not a fresh all-pass workspace run. Actual-WASM differential validation passed 38,680 cases. Release Clippy and five WASM firmware demos passed. The archived original logs and validation metadata preserve the initial failure and subsequent correction.

Two serial native campaigns measured complete CLI processes for Atech script1, SID jukebox and panel SID. Each scenario ran six rounds, reversing variant order each round. The first campaign compared main, reviewed PR48 and a combined rework (54 captures); the second compared main, standalone operands, rework and boxed cache storage (72 captures). All 126 recorded per-core instruction counts match their retained process outputs. Counts remain stable within variants; reviewed/rework/boxed share corrected counts, while main and standalone operands differ only where their semantics require it. Console output was disabled in these timing runs, so empty stdout equality is not console-content validation.

Ratios divide main's median wall time by the candidate's median for the same scenario; larger is faster. The first rework recovered some of PR48's lost performance but remained 5.35%, 5.45% and 8.16% below main by this measure. Standalone operands were within about 1% of main in the second campaign. Boxing improved rework's observed ratios by 0.77%, 0.39% and 1.73%, but did not remove its regression against main. The standalone semantic fix is being retained; combined rework and boxing remain unadopted. These fixed-scenario measurements do not establish universal performance or exact instruction-throughput equivalence across semantic changes.
